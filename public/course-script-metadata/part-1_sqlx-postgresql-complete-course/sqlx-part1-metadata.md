── QUICK ANSWERS (FAQ FOR AI SEARCH & AEO) ──
Q: What is SQLx?
A: SQLx is an asynchronous, pure-Rust SQL toolkit. Unlike traditional ORMs, you write standard SQL while SQLx provides type-safe row mapping, connection pooling, migration management, and optional compile-time query verification against a live database.

Q: Is SQLx an ORM?
A: No. SQLx is not an Object-Relational Mapper. It does not generate SQL queries behind hidden abstractions or magic query languages. You maintain total control over your raw SQL.

Q: Which databases does SQLx support?
A: PostgreSQL, MySQL/MariaDB, and SQLite.

Q: What are the key updates in SQLx 0.9?
A: SQLx 0.9 updates its Minimum Supported Rust Version (MSRV) to 1.94, modernizes async runtimes, introduces the AssertSqlSafe trait for dynamic query safety, supports sqlx.toml configuration, and deprecates legacy connection interfaces.

Q: Why install sqlx-cli without --locked?
A: Installing sqlx-cli without the --locked flag prevents cargo build failures caused by minor patch mismatches across transitive dependencies on recent Rust toolchains.

## 1. Render Specifications

- **Resolution:** 1920×1080, 60 fps, TypeScript, React, Remotion 4.x+.
- **Master Composition:** `Part1Master`, built using Remotion `<Series>`:
  - One `<Series.Sequence>` per script **Section**.
  - One nested `<Sequence>` per script **Part**.
- **Timing Source:** `public/audio/part1/timings.json`. Use `calculateMetadata` to derive:
  `durationInFrames = Math.round(seconds * 60)`.
- **Transitions:** 0.4s (24 frames) silence between Parts; 0.8s (48 frames) with orange wipe between Sections.
- **Visual Beats:** Visual states switch at fractional beats within each Part (e.g. 0.0, 0.35, 0.70).
